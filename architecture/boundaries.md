# Boundaries

- `Conclave.Core` depends on no other Conclave project.
- `Conclave.Infrastructure`, `Conclave.Repository`, `Conclave.Providers`, and `Conclave.Validation` implement technical capabilities.
- `Conclave.Orchestration` composes capabilities and contains use-case slices.
- `Conclave.Cli` is the console transport and composition root.
