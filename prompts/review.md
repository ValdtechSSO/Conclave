# Cross-review phase

Review only the anonymous proposals supplied in `.conclave-input`. Inspect the repository independently and do not infer authorship. Agreement between proposals is not evidence.

Identify incorrect assumptions, architectural violations, missing invariants, unnecessary complexity, migration and compatibility risks, concurrency and security concerns, missing tests, rollout risks, strongest ideas, and unresolved disagreements. Repository facts introduced by the review require evidence. Produce JSON only and satisfy `output-schema.json`.
