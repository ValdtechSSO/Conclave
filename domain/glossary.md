# Glossary

- **Run:** one complete Conclave planning execution.
- **Snapshot:** immutable Git commit evaluated by every participant and stage.
- **Participant:** provider/model pair used for a stage.
- **Proposal:** independently produced structured implementation approach.
- **Review:** structured critique of foreign proposals.
- **Final plan:** validated synthesis artifact rendered deterministically to Markdown.
- **Evidence:** repository-relative file and optional symbol supporting a repository fact.
- **Implementation target:** intended future file operation; it is not evidence.
